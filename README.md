# Project-IronSight
AI-powered gym equipment detection and exercise intelligence.
Project IronSight is an AI-powered web app that identifies gym equipment from a photo using a custom-trained YOLO object detection model. Upload an image and get the equipment name, the primary muscle it targets, exercise guidance, and a demo video — all in one click.

### Used the Bangkit Dataset of Gym Equipment Object Detection :

https://universe.roboflow.com/akrm-saad-m-d/gym-equipment-object-detection-dbwyy/dataset/1
